Cara pakai:
1. Upload semua file ke hosting sederhana, misalnya Netlify, Vercel, GitHub Pages, atau server sendiri.
2. Buka URL dari iPhone menggunakan Safari.
3. Tekan Share.
4. Pilih Add to Home Screen.
5. Aplikasi akan muncul seperti app biasa.

Catatan:
- Data tersimpan di browser HP melalui localStorage.
- Untuk kebutuhan sederhana sebagai kalkulator, ini cukup.
- Kalau ingin data tersimpan online lintas HP, perlu database/backend tambahan.
