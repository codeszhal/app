收支记录 PWA v2

Cara update di GitHub:
1. Extract ZIP.
2. Upload/replace file berikut ke root repository:
   - index.html
   - style.css
   - app.js
   - manifest.json
   - service-worker.js
3. Commit changes.
4. Pastikan GitHub Pages: main / (root).
5. Buka https://codeszhal.github.io/app/

Fitur:
- Tabel dengan nama persis seperti contoh Excel.
- Kolom utama: 姓名, 收入, 支出.
- Bisa tambah baris.
- Bisa tambah kolom tambahan.
- Total otomatis di baris 合计.
- Panel kanan otomatis membandingkan total tabel dan total ringkasan.
- Jika cocok: SUCCESS hijau.
- Jika gagal / angka tidak valid: FAILED merah.
- Data tersimpan otomatis di browser HP.
